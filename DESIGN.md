Цель и роли: создание постов зарегистрированными пользователями, гости читают посты.



MVP (минимальная версия) — то, без чего сайт не имеет смысла.
Сценарии: 
- Как гость, я хочу читать посты без регистрации, чтобы понять, интересен ли блог. (MVP, страница "posts")
- Как гость, я хочу зарегистрироваться по email и паролю, чтобы публиковать свои посты. (MVP, страница "register")
- Как гость, я хочу войти, чтобы мои действия были привязаны ко мне. (MVP, страница "login")
- Как пользователь, я хочу выйти, чтобы действия не были привязаны к текущему аккаунту. (MVP, страница "logout")
- Как пользователь, я хочу написать пост, чтобы поделиться мыслями. (MVP, страница "add")
- Как автор поста, я хочу изменять и удалять только свои посты, чтобы никто не испортил мой текст. (MVP, страница "edit" и "delete")
- Как гость, я хочу прочитать политику сайта, чтобы знать, как используются мои данные. (потом)
- Как гость, я хочу пользоваться меню, чтобы иметь быстрый доступ к страницам. (MVP, на каждой странице в шапке сайта)
- Как гость или пользователь, я хочу читать пост, чтобы быть в курсе событий. (MVP, страница "post/<id>")




Страницы:
1. главная - / - GET (только форма (GET)) - все
2. регистрация - /register - POST, GET (отображение формы (GET) и кнопка изменения данных (POST)) - гость
3. вход - /login - POST, GET (отображение формы (GET) и кнопка изменения данных (POST)) - гость
4. выход - /logout - POST (только кнопка изменения данных (POST)) - пользователь
5. просмотр поста - /post/<id> - GET (только форма (GET)) - все
6. создание поста - /add - GET, POST (отображение формы (GET) и кнопка изменения данных (POST)) - пользователь
7. редактирование поста - /edit/<id> - GET, POST (отображение формы (GET) и кнопка изменения данных (POST)) - автор поста
8. удаление поста - /delete/<id> - POST (только кнопка изменения данных (POST)) - автор поста





Данные:
поле | тип (INTEGER или TEXT) | ограничения | зачем

Users
id | integer | AUTOINCREMENT PRIMARY KEY | уникальный идентификатор пользователя
surname | text | - | фамилия пользователя
name | text | - | имя пользователя
patronymic | text | - | отчество пользователя
email | TEXT NOT NULL UNIQUE | NOT NULL | почта
password_hash | text | - | хеш пароля
created_at | text | DEFAULT CURRENT_TIMESTAMP | дата регистрации



Posts
id | INTEGER | PRIMARY KEY, AUTOINCREMENT | идентификатор поста
user_id | INTEGER, NOT NULL, users(id) | связь с таблицей users для отображения автора поста
title | TEXT | NOT NULL | заголовок
text | TEXT | NOT NULL | текст поста
created_at | TEXT | DEFAULT CURRENT_TIMESTAMP | дата создания
